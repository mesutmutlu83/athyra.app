# Sportapp (Athyra)

This repository contains the Sportapp application project and its [product and engineering documentation](docs/README.md). The [project brief](docs/01-product/project-brief.md) records the initial source, while the [coverage register](docs/01-product/document-coverage.md) identifies missing facts, unresolved decisions, and verification gaps.

The reusable Codex team is installed for this user under `~/.agents/codex-team/` and `~/.codex/`; it is shared with other projects. Run the global `project-bootstrap` skill when adding a new project or reconciling this project's documentation.
