# Definition of Done

Done means:
- approved acceptance criteria are met;
- implementation is within scope;
- applicable quality-gate commands pass;
- QA_APPROVED for production code changes;
- CODE_REVIEW_APPROVED when required by adaptive routing/risk;
- sufficient regression evidence for production behavior-changing work;
- security/data/architecture/ops reviews pass when required;
- durable docs match the implementation when the change affects documented behavior/contracts/architecture;
- verified findings and reusable lessons are reflected in the owning domain's canonical docs when applicable; unresolved claims have an owner and status;
- release notes/changelog are updated when applicable;
- no temporary artifacts or secrets are included;
- unresolved risks are explicitly documented rather than hidden.
