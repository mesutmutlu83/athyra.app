# Shared Agent Knowledge and Lessons

This is the canonical index for cross-department agent-system findings. Product and system facts remain in [Sportapp docs](../../../../docs/README.md). The [knowledge process](../processes/knowledge-management.md) defines evidence, validation, review, and supersession.

- [Agent-run lessons](agent-effectiveness.md) records observed failures and verified process corrections.
- [Agent-system comparison](agent-system-comparison-2026-09-28.md) is dated external evidence, not an app requirement.
- [Weekly scan status](weekly-scan-status.md) records the installed agent research job and review state.

Department-specific agent workflow lessons belong in that department's `knowledge/` directory; cross-department routing and tool lessons belong here.
