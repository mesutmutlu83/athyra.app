# Release Operating Rules and Process

These are agent operating instructions. Canonical product and system facts remain in [department documentation](../../../docs/08-release/README.md); shared gates remain in [AGENTS.md](../../../AGENTS.md).

## Rules

The root Delivery Orchestrator owns final release evaluation. Release has no separate specialist prompt or private approval shortcut.

## Process

Collect applicable PM, QA, Review, Security, Operations, and Documentation evidence, check the release gate, and record only supported release claims.
