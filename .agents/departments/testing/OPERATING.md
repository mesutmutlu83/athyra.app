# Testing Operating Rules and Process

These are agent operating instructions. Canonical product and system facts remain in [department documentation](../../../docs/06-testing/README.md); shared gates remain in [AGENTS.md](../../../AGENTS.md).

## Rules

QA approval is independent of implementation; Code Review is independent for L2/L3 and triggered L1. A failed required gate remains blocking.

## Process

Validate acceptance and regression evidence with targeted checks; review the diff for correctness and risks; hand root a short gate decision.
