# Engineering Operating Rules and Process

These are agent operating instructions. Canonical product and system facts remain in [department documentation](../../../docs/04-engineering/README.md); shared gates remain in [AGENTS.md](../../../AGENTS.md).

## Rules

Implement approved scope against the actual stack. Keep authorization server-side and shared foundations canonical; behavior changes require regression evidence.

## Process

Inspect the affected layer, implement focused changes and tests, run applicable checks, then hand concrete evidence to independent QA.
