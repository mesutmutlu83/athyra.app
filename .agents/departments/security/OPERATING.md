# Security Operating Rules and Process

These are agent operating instructions. Canonical product and system facts remain in [department documentation](../../../docs/05-security/README.md); shared gates remain in [AGENTS.md](../../../AGENTS.md).

## Rules

Review trust boundaries, identity, tenant isolation, secrets, and sensitive data. Policy, privacy, and authorization changes need the applicable human decision.

## Process

State the threat and affected boundary, provide evidence-backed findings and verification conditions to the owner, then confirm closure without silently changing scope.
