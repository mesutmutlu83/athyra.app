# Product Roadmap

The source brief defines gated stages rather than delivery-date estimates.

Stage outcomes are checked against [proposed outcome measurement](outcome-measurement.md) as evidence becomes available. The measurement framework does not make a stage delivered or set a launch target.

| Stage | Outcome |
|---|---|
| D0 | Current-state gap analysis, open decisions, source/permission/catalog matrices, iOS support decision, admin/billing/CRM contracts |
| D1 | Identity, consent, AI gateway foundations, native iOS shell, secure admin staff shell |
| D2 | Athlete profile, read-only application/HealthKit history, coverage reporting, CRM identity backfill |
| D3 | Versioned multi-sport catalog, typed content/session schemas, product/membership/financial foundations |
| D4 | Multi-sport weekly planning and approval with entitlement separation |
| D5 | Session guidance, imported-record/user-report loop, offline state, minimum CRM/support |
| D6 | Cross-sport adaptation and, only if approved, verified billing-provider flow |
| D7 | Native coach workspace, content workflow, operational admin dashboard |
| D8 | Lifecycle, export/deletion/revocation, accessibility, release/runbook completion |
| D9 | Real-device/browser/provider verification and controlled release |
| D10 | Separately approved expansion such as Android, coach web, institutions, or added providers |

P0 does not include Android, a separate coach web product, watch/device integration, live workout recording, full sales automation, accounting/e-invoicing, or unapproved advanced coaching automation.

## Extension 01 delta sequence
