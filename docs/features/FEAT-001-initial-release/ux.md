# FEAT-001 UX

See `docs/02-ux/user-flows.md`, `design-system.md`, and `accessibility.md`.

Required product-language distinctions include planned vs completed, imported vs user-reported vs derived, source event vs last sync, login vs data permission, membership vs entitlement vs payment, renewal-off vs expired, requested refund vs confirmed refund, and unavailable vs denied vs no data observed.
