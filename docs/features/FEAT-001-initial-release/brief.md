# FEAT-001 — Sportapp Initial Release

Status: discovery / D0. Priority: P0 program.

## Outcome

Deliver a native iPhone athlete+coach product and private admin web backed by one secure application platform. Users can establish identity, optionally import existing application health/activity records read-only, build and approve multi-sport weekly plans with a selected AI connection, adapt plans from observed/user-reported outcomes, and manage consent/history. Authorized staff can operate users, membership/entitlements, minimum CRM/support, and—only under an approved channel—billing evidence.

## In scope

The P0 domains summarized in `requirements.md`, including iPhone 12+ compatibility, auth, consent, data import, one owner-operated admin-configured Ollama provider behind extensible adapters, multi-sport catalog/planning, native coach workspace, admin/RBAC, CRM/support, membership/entitlements, and verified StoreKit billing for Pro.

## Out of scope

Measurement, live workout recording, sensors/devices, GPS recording, watch apps, writing external health stores, Android, separate coach web, full CRM/marketing automation, accounting/e-invoicing, and unapproved advanced medical/technical coaching.

The detailed requirement and test inventory remains in `docs/01-product/project-brief.md`.
