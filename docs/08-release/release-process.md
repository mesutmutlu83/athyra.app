# Release Process

Release is blocked until the applicable P0 source requirements have traceable evidence, approved Human Decision Gates are recorded, quality commands pass, security/data/compatibility reviews pass, and real-device/browser/provider checks are clearly distinguished from mocks.

Unverified combinations remain `NOT_RUN`, `BLOCKED_EXTERNAL`, or `NOT_APPLICABLE_FOR_FREE_MODE`; none are equivalent to pass. Paid mode cannot use free-mode non-applicability to skip provider sandbox evidence.
